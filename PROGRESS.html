🛠️ שלב 0 — הכנת הסביבה הושלם

מתקינים את הכלים שנצטרך כדי לפתח את הפרויקט
  • בדיקת מה מותקן במחשב (Git קיים, Node חסר)
  • התקנת Node.js v24.18 (כולל npm 11.16)
  • פתיחת חשבון MongoDB Atlas (נעשה בשלב 2)
💡 מה זה Node.js? סביבה שמריצה JavaScript על השרת. npm = חנות הספריות שממנה הורדנו את Express, Mongoose, Pino.

🧭 שלב 1 — שלד 4 השירותים הושלם

4 פרויקטים נפרדים (4 processes אמיתיים), כל אחד עם package.json משלו
  • a-logs-service · פורט 3000 · /api/logs
  • b-users-service · פורט 3001 · /api/users, /api/add
  • c-costs-service · פורט 3002 · /api/add, /api/report
  • d-about-service · פורט 3003 · /api/about
✅ הותקנו הספריות בכל שירות: express, mongoose, pino, pino-mongodb, dotenv + jest & supertest לבדיקות.

🗄️ שלב 2 — מסד הנתונים והמודלים הושלם

בונים את ה-Schemas ב-Mongoose בתוך תיקיית models
  • מודל User (id:Number, first_name, last_name, birthday:Date)
  • מודל Cost (description, category, userid, sum:Double)
  • מודל Log · מודל Report (Computed Pattern)
  • חשבון MongoDB Atlas נפתח + חיבור נבדק בהצלחה ✅
✅ מחובר למסד בענן בשם cost_manager. מחרוזת החיבור נשמרה בקובץ .env נפרד (לא בקוד).

⚙️ שלב 3 — בניית ה-Endpoints הושלם

כותבים את הלוגיקה של כל בקשה (Express.js) — נבדק חי מול כל 8 ה-endpoints
  • הוספת משתמש / קבלת משתמש+total / רשימת משתמשים
  • הוספת הוצאה / דו"ח חודשי (Computed Design Pattern)
  • רשימת לוגים / פרטי צוות הפיתוח
  • validation + הודעות שגיאה בפורמט {id, message}
✅ כל ה-endpoints נבדקו חי: הוספה, דו"חות, total, כפילויות, קטגוריה שגויה — הכל מחזיר את התשובה הנכונה.

📝 שלב 4 — לוגים (Pino) + קובץ .env הושלם

רישום כל בקשה למסד הנתונים + ניהול סודות
  • Pino כותב לוג ל-MongoDB על כל בקשה + כל גישה ל-endpoint
  • קובץ .env בכל שירות (מחרוזת חיבור + פורט)
✅ נבדק חי: הלוגים נשמרים ל-collection בשם logs ונקראים דרך /api/logs.
